# Changelog

All notable changes to this package are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the version numbers follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-11

### Added

- `Konsole.Info`, `Konsole.Warning` and `Konsole.Error` with optional channel and context object.
- Konsole window (`Tools/Konsole`): search, collapse, channel filter, severity toggles, Error Pause, font size, save to text file.
- Stack trace panel. A click on a frame opens the file at the line.
- Capture of Unity logs and compiler messages in the `unity` channel.
